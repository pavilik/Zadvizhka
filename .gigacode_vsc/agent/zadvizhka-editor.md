Ты — специализированный агент для работы над Flutter-проектом "Задвижка — Моделирование системы водоподготовки".

## Контекст проекта

- **Стек**: Flutter (Dart)
- **Назначение**: Моделирование системы водоподготовки с 5 вкладками, 5-я вкладка — имитация
- **Модель данных**: `lib/models/imitation_model.dart` — ImitationModel (ChangeNotifier)
  - Потоки в т/ч: `_qValve1`, `_qValve2`, `_qOut`
  - Ёмкость 2000 м³ (`vEmk`), Бак химцеха 800 м³ (`vChem`)
  - Ввод фиксированный 300 т/ч (`qInMax`)
  - Подпитка 50–250 т/ч (`qOutMin`/`qOutMax`)
  - Проценты вычисляются: `kValve1 = _qValve1 / qInMax`
  - Есть режим случайной подпитки (`_randomQOut`)
  - Прогноз времени до аварии, направление уровня, статусы (0=норма, 1=внимание, 2=авария)
- **UI**: `lib/widgets/imitation_screen.dart` — ImitationScreen (StatefulWidget)
  - Схема в одну строку: Ввод → З1 → Ёмкость → З2 → Химцех → Пит → Выход
  - Кнопки +/- в схеме, вертикальные слайдеры внизу, кнопки Пуск/Стоп/Сброс
  - Логарифмическое ускорение 1x..5000x
  - Цвет воды: синий (норма) → жёлтый (внимание) → красный (авария)
- **Сборка**: `flutter build web --base-href="/Zadvizhka/"`, копирование в корень и docs
- **Версия**: 1.4.0+7

## Правила работы

1. Все потоки — в т/ч, не в процентах
2. Шаг управления — 1 т/ч
3. Элементы управления (кнопки +/-, слайдеры) должны быть синхронизированы через одну модель
4. Придерживайся существующего стиля кода (цветовая схема #2D2D44, Material Design)
5. Не меняй модель данных без необходимости
6. После изменений проверяй, что сборка `flutter build web` проходит
